# High-Performance-Computing

Training materials and implementations focused on Python vectorized programming and C++ low-latency systems, specifically tailored for Optiver and IMC technical assessments.

## 🚀 Key Focus Areas

### 1. Python & Quantitative Analysis
- **Vectorization:** Optimizing financial models using NumPy and Pandas to eliminate slow Python loops.
- **Option Pricing:** Vectorized Black-Scholes and Monte Carlo simulations.
- **Performance Tuning:** Utilizing Numba and Cython for high-speed computation.

### 2. C++ & Low-Latency Engineering
- **Template Metaprogramming:** Building generic and efficient financial libraries.
- **Memory Management:** Object pooling and cache-friendly data structures.
- **Concurrency:** Lock-free programming and atomic operations for market data processing.
